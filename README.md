# Finals

Municipality of Milaor web administration panel and mobile application.

- `web/`: React and Vite web application. Run `npm ci` and `npm run dev` from this folder.
- `mobile/`: Flutter mobile application. Copy `.env.example` to `app.env`, supply your Supabase public configuration, then run `flutter pub get` and `flutter run`.

See each project's README and documentation for setup details.
